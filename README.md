# Acompanhamento de Projetos SISRAMOS

Aplicacao Vite/React para acompanhar validade, responsaveis e status dos projetos por cliente.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build para Vercel

```bash
npm run build
```

O projeto usa `dist` como pasta de saida do Vite e pode ser acompanhado no Vercel a partir dos deploys conectados ao repositorio do GitHub.
